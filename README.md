# SQL and Python Practice: Hiring Data

A learning project. I'm practising SQL and Python on a small, made-up hiring dataset. It is not production work, and the data is not real.

## What's inside
- `candidates.csv`: 60 sample candidates with role type, source, furthest stage and days in process.
- `queries.sql`: 6 beginner SQL queries with comments (counts, grouping, averages, CASE).
- `funnel_analysis.py`: a short Python script (pandas) that builds a hiring funnel and prints conversion between stages.

## How to run the Python script
1. Install Python and pandas (`pip install pandas`).
2. Keep `candidates.csv` and `funnel_analysis.py` in the same folder.
3. Run `python funnel_analysis.py`.

## What I'm practising
Reading data, grouping and counting, conditional logic, and turning hiring numbers into a funnel.

## Notes
All candidates are made up. Never upload real candidate data to a public repository.
